# Vaishnavi Arts - Art Store Sales App

Final Workshop Project - Electron.js + Supabase

## Features
- Desktop App using Electron.js
- Sales Entry Form (Customer Name, Amount)
- Total Sales Calculation
- Supabase Connected for Data Storage (CRUD)
- Dashboard with Sales List

## How to Run
npm install
npm start

## Technologies
- Electron.js
- HTML, CSS, JavaScript
- Supabase
- Node.js
